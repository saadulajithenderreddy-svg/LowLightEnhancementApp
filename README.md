# ✨ LumiEnhance AI

### Deep Learning Based Low-Light Image Enhancement

LumiEnhance AI is a deep learning application that improves the visibility of dark and low-light images using a trained U-Net neural network.

## 🚀 Features

- 📤 Upload low-light images
- 🧠 U-Net deep learning model
- ✨ AI-powered image enhancement
- 📷 Original and enhanced image comparison
- ⬇️ Download enhanced images
- 🌐 Streamlit web application
- 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- PyTorch
- Torchvision
- U-Net
- Streamlit
- Pillow
- Git & GitHub
- Git LFS
